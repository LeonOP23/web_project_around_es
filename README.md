# Tripleten web_project_around_es

## 📌 Descripción

Este proyecto es una aplicación web interactiva que permite a los usuarios gestionar su perfil y una colección de tarjetas con imágenes de distintos lugares.

El usuario puede editar su información personal, agregar nuevas tarjetas con imágenes, interactuar con ellas mediante "likes", eliminarlas y visualizar las imágenes en tamaño completo dentro de un modal.

Además, el proyecto implementa validación de formularios y diferentes formas de interacción con ventanas emergentes para mejorar la experiencia de usuario.

---

## 🚀 Tecnologías utilizadas

- HTML5
- CSS3 (Metodología BEM)
- JavaScript (Vanilla JS)
- Programación Orientada a Objetos (POO)
- Módulos ES6 (`import` / `export`)

---

## ⚙️ Funcionalidades principales

- Edición de perfil (nombre y descripción)
- Creación dinámica de tarjetas
- Eliminación de tarjetas
- Botón de "like" interactivo
- Visualización de imágenes en modal
- Validación de formularios en tiempo real
- Cierre de modales mediante:
  - Botón de cierre
  - Clic en el overlay
  - Tecla **Esc**
